# Vibrance 2026 – Responsive College Event Portal

A front-end mini project based on the College Event Portal requirements.

## Features
- Responsive Bootstrap navigation
- Festival homepage and announcements
- Dynamic event cards
- Event schedule table
- Event registration form with JavaScript validation
- Registration success modal
- Responsive image gallery
- Contact/enquiry form
- Mobile, tablet and desktop responsive layout
- DOM manipulation and event listeners

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Run
Open `index.html` directly in a browser, or run:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Project Structure
- `index.html` – page structure and sections
- `style.css` – custom styling and responsive design
- `script.js` – events, DOM updates, validation and interactions

## Note
The gallery uses remote Unsplash images, and Bootstrap is loaded from a CDN. An internet connection is therefore needed for those external assets.
